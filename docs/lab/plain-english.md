# Player text

Write full grammatical sentences for instructions, state, history, dialogue and errors. Short control labels may name an action or object. Say literally what happens. Use one name for each thing. Explain a game term on first use. Introduce one new idea at a time. Use familiar words and short sentences. Aim for grade 7 instructions; dialogue may be richer but must remain grammatical. State uncertainty without guessing motives. Cut unnecessary words.

Preserve names, Turkish words, culture, rules and difficulty. Project stored simulation text for display when editing the stored string would change replay. Keep diagnostics behind exact `?lab=1`. An ordinary error must name the failed action and preserve existing saves and receipts. It may point to retry or Feedback without promising recovery.

The frozen shared reading checker flags source candidates, including internal and historical strings. Its counts are heuristics, not reading grades or counts of rendered sentences.
